# 浅色响应式镜头库视觉改版

## 目标

把现有深色镜头库改成轻盈、浅色、圆角更大的灵感目录。桌面端左侧集中筛选，右侧展示自适应卡片；卡片预览进入视口后默认静音循环播放。

## 视觉方向

- 页面背景使用暖灰白，内容面板和卡片使用白色。
- 主文字使用接近黑色的深灰，辅助文字使用中性灰。
- 淡紫、淡绿、浅橙用于选中态、标签和少量强调，不大面积铺色。
- 卡片圆角为 22px，筛选面板和详情弹窗为 24–28px，按钮与标签使用胶囊圆角。
- 使用细边框和轻阴影分层，去掉工业感强的深色描边和高对比橙色。

## 页面结构

### 顶部

保留“快速找到下一镜”、简短说明和镜头统计，缩短顶部高度并使用浅色背景。

### 左侧筛选

桌面端使用约 260px 的粘性侧栏，依次放置：

1. 搜索框
2. 分类
3. 等级
4. 标签

侧栏自身为白色大圆角面板。分类和等级使用整行按钮，标签使用可换行的胶囊按钮。

### 右侧内容

右侧顶部显示匹配数量和当前分类，下面直接进入卡片网格。

网格不固定列数，使用可用宽度自动排布：

```css
grid-template-columns: repeat(auto-fill, minmax(300px, 1fr));
```

预期效果为超宽屏约 4–5 列、普通桌面约 3 列、窄屏约 2 列、手机 1 列。实际列数由右侧区域宽度决定。

## 卡片

- 预览保持 16:9，并与卡片共享 22px 外圆角。
- 标题、等级、分类和 ID 控制在两行信息内。
- 取消“悬停预览”提示，改成简洁的播放状态标识。
- hover 仅用于轻微上浮、阴影和边框变化，不再控制播放。

## 自动播放

### MP4

- 卡片进入视口附近后加载资源。
- 真正进入视口时自动静音循环播放。
- 离开视口立即暂停。
- 重新进入视口时继续播放。

### 本地 Player

- iframe 只在接近视口时创建。
- iframe 加载完成且卡片位于视口内时发送 `play`。
- 离开视口时发送 `pause`。
- hover 和 focus 不再决定播放状态。

### 无障碍与性能

- 系统开启“减少动态效果”时不自动播放。
- 详情页保留用户控制，不强制自动播放。
- 加载或播放失败只影响当前卡片，并显示浅色占位。

## 响应式

- 大于 1020px：左侧粘性筛选栏，右侧自适应网格。
- 720–1020px：筛选栏缩窄，卡片通常为 2 列。
- 小于 720px：筛选移到内容顶部，不再粘性并改成紧凑分组；卡片单列或由宽度自然决定。

## 详情弹窗

详情页改为浅色大圆角面板，继续保持大预览区域。样式切换、配方信息和按钮使用与首页一致的淡色标签体系。

## 测试

- 页面结构测试确认筛选栏位于卡片区域左侧。
- 样式测试确认浅色变量、大圆角和 `auto-fill/minmax` 网格存在。
- MP4 测试确认视口进入播放、离开暂停，并尊重减少动态效果。
- Player 测试确认视口状态驱动 `play/pause`，而不是 hover。
- 运行完整测试、类型检查和生产构建。
