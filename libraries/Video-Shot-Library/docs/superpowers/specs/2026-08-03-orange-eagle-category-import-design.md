# 橘色镜头分类导入设计

## 目标

把站点中“运镜与空间”“数据与指标”“文字与字卡”三类镜头统一为橘色主视觉，并合并到现有 Eagle 镜头库。最终保持每个站点样式键恰好一个 Eagle 条目。

## 范围

- 目标共 98 个唯一镜头。
- 已在 Eagle 的 video-shotcraft 47 个镜头原地更新，不重复导入。
- 尚未转移的 51 个镜头新增到 Eagle：Remocn 31 个、Remotion Bits 13 个、观点卡 7 个。
- 继续使用现有“运镜与空间”“数据与指标”“文字与字卡”分类文件夹。

## 颜色处理

- 统一强调色为 `#FF6900`。
- 使用同一套确定性 3D LUT：低饱和黑白灰保持原样；有彩色倾向的强调区域统一映射到橘色，并保留原始亮度与层次。
- 不使用普通色相旋转，避免不同源色产生不一致结果。

## 处理流程

1. 以 `public/data/library.json` 的 collection、category、style key 为唯一来源。
2. 对无现成 MP4 的 Remocn 和 Remotion Bits 组合先按原 composition 渲染。
3. 对全部目标 MP4 应用统一橘色 LUT。
4. 已存在条目先备份原视频，再原子替换 Eagle 内视频并刷新缩略图。
5. 缺失条目通过 Eagle API 导入到对应分类，写入来源、系列、类型、镜头卡、样式和橘色主色标签。

## 去重与错误处理

- 去重键为站点 style key；写入前再次查询 Eagle。
- 若同名恰好一条则原地更新，零条才新增，多于一条则停止该条并记录冲突。
- 单个渲染或换色失败不影响其他镜头；失败项保留原文件并进入复核清单。
- 所有替换使用临时文件验证后原子覆盖，避免中断造成损坏。

## 验收

- 98/98 个目标 style key 在 Eagle 中各恰好一条，重复数为 0。
- 三个分类数量与站点清单一致。
- 所有 MP4 可解码，尺寸、时长、帧率有效，Eagle 可生成预览。
- 抽取开头、中段和结尾帧检查：强调色接近 `#FF6900`，黑白灰未被整体染色。
- 已有 47 条保持原 ID、名称、分类和说明；只新增 51 条。
