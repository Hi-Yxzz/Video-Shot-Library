# 移除首页左上角品牌区

## 目标

从镜头库首页顶部移除整行品牌信息，让主标题“快速找到下一镜”成为页面最上方的主要内容。

## 改动范围

- 删除 `VIDEO SHOTCRAFT` 标志、文字和 GitHub 链接。
- 删除 `LOCAL INDEX / CN` 标签。
- 删除只服务于该品牌区的 CSS。
- 保持主标题、统计、搜索、筛选、卡片、详情页和镜头数据不变。

## 响应式布局

品牌区删除后，桌面端和移动端均由现有 `hero-copy` 自然顶上，不增加替代占位或额外顶部留白。

## 验证

- 服务端渲染的首页不再包含 `VIDEO SHOTCRAFT` 或 `LOCAL INDEX / CN`。
- 页面仍包含“快速找到下一镜”。
- 现有测试、类型检查和生产构建通过。

## 发布

使用当前线上 Sites 源码作为基线，只叠加本次品牌区删除，保存为新版本；公开发布前取得用户确认。
